## 🧠 Concepts Involved

### 🎨 Image Negatives

- **Color Negative:**  
  - Each pixel value in all three RGB channels is subtracted from 255, inverting the color.
- **Grayscale Negative:**  
  - Convert the image to grayscale, then invert each pixel value (255 - pixel).

---

## 🛠️ Image Processing Steps

1. **Image Acquisition:** Load the original color image.
2. **Color Negative:** Invert all RGB channels.
3. **Grayscale Conversion:** Convert the image to grayscale.
4. **Grayscale Negative:** Invert the grayscale image.
5. **Visualization:** Display all results for comparison.

---

## 📝 Code Explanation (Line by Line)

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt
```
- **Why?**
  - `cv2`: For image reading and processing.
  - `numpy`: For numerical operations.
  - `matplotlib.pyplot`: For displaying images.

```python
img = cv2.imread('wce_campus.jpg')
img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)  # Convert BGR to RGB
```
- **Why?**  
  - Reads the image file into a NumPy array (default in BGR format).
  - Converts image from OpenCV’s default BGR to standard RGB for correct color display in matplotlib.

```python
negative_color = 255 - img
```
- **Why?**  
  - Computes the negative of the color image by inverting all RGB channels.

```python
gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)
negative_gray = 255 - gray
```
- **Why?**  
  - Converts the RGB image to grayscale.
  - Computes the negative of the grayscale image.

---

### 📊 Displaying Results

```python
plt.figure(figsize=(10, 8))
plt.subplot(2, 2, 1)
plt.title('Original Image (24-bit Color)')
plt.imshow(img)
plt.axis('off')

plt.subplot(2, 2, 2)
plt.title('Negative Image (24-bit Color)')
plt.imshow(negative_color)
plt.axis('off')

plt.subplot(2, 2, 3)
plt.title('Grayscale Image (8-bit)')
plt.imshow(gray, cmap='gray')
plt.axis('off')

plt.subplot(2, 2, 4)
plt.title('Negative Grayscale Image (8-bit)')
plt.imshow(negative_gray, cmap='gray')
plt.axis('off')

plt.tight_layout()
plt.show()
```
- **Why?**
  - Arranges the original, negative, grayscale, and negative grayscale images in a 2x2 grid for easy comparison.
