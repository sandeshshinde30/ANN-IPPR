# 📸 Image Edge Detection: Sobel, Prewitt & Canny Operators 🧪

## 📚 Concept Overview

### What is Edge Detection? 🧠
Edge detection identifies **sharp changes in brightness** in an image. These changes often correspond to:
- Object boundaries 📦
- Surface markings 🎨
- Shadows 🌑

### 1️⃣ Sobel Operator 🧮
- Uses **gradient calculation** with weighted kernels
- Detects edges in **X (horizontal)** and **Y (vertical)** directions
- Combines both gradients for final edge map 📈
- Robust against noise due to weighted averaging 🛡️

### 2️⃣ Prewitt Operator ➕
- Similar to Sobel but uses **uniform weights**
- Simpler kernel design
- Good for basic edge detection needs
- More sensitive to noise than Sobel 🌊

### 3️⃣ Canny Edge Detector 🎯
- Multi-stage algorithm 🔁
- Includes:
  - Noise reduction 🧹
  - Gradient calculation 📐
  - Non-maximum suppression 🧹
  - Hysteresis thresholding 🧱
- Produces **thin, precise edges** with threshold control

### 🧾 Code with Explanations

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

# 📷 Load image (replace 'img.jpg' with your image path)
img = cv2.imread('img.jpg')
if img is None:
    raise FileNotFoundError("Image not found! Check file path 🧐")

# 🌑 Convert to grayscale (edges work best on single-channel images)
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# 🔍 Sobel Edge Detection
sobel_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)  # Horizontal edges
sobel_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)  # Vertical edges
sobel_edges = cv2.magnitude(sobel_x, sobel_y)          # Combine both directions

# ➕ Prewitt Edge Detection (custom kernels)
prewitt_kernel_x = np.array([[-1, 0, 1], [-1, 0, 1], [-1, 0, 1]])
prewitt_kernel_y = np.array([[-1, -1, -1], [0, 0, 0], [1, 1, 1]])
prewitt_x = cv2.filter2D(gray, -1, prewitt_kernel_x)
prewitt_y = cv2.filter2D(gray, -1, prewitt_kernel_y)
prewitt_edges = cv2.magnitude(prewitt_x, prewitt_y)

# 🎯 Canny Edge Detection
canny_edges = cv2.Canny(gray, threshold1=100, threshold2=200)

# 🖼️ Display results
plt.figure(figsize=(12, 8))

plt.subplot(2, 2, 1), plt.imshow(gray, cmap='gray'), plt.title('Original 📷')
plt.subplot(2, 2, 2), plt.imshow(sobel_edges, cmap='viridis'), plt.title('Sobel 🔍')
plt.subplot(2, 2, 3), plt.imshow(prewitt_edges, cmap='plasma'), plt.title('Prewitt ➕')
plt.subplot(2, 2, 4), plt.imshow(canny_edges, cmap='inferno'), plt.title('Canny 🎯')

plt.tight_layout()
plt.show()

# 💾 Optional: Save results
cv2.imwrite('sobel_edges.jpg', sobel_edges)
cv2.imwrite('prewitt_edges.jpg', prewitt_edges)
cv2.imwrite('canny_edges.jpg', canny_edges)
```

## 🧠 Key Concepts Explained

### Why Grayscale? 🌈→⚪
Edge detection works on **intensity gradients** - grayscale images contain:
- Brightness information only ✅
- No color distractions ❌
- Single channel instead of 3 (RGB) 📉

### Threshold Tuning 🎚️
For Canny:
- `threshold1`: Lower bound (weak edges)
- `threshold2`: Upper bound (strong edges)
- Try different values (e.g., 50/150 or 150/250) to fine-tune results

### Kernel Comparison 📊

| Operator | Kernel Size | Weighted? | Noise Resilience | Edge Thickness |
|---------|------------|----------|------------------|----------------|
| Sobel   | 3×3        | ✅ Yes    | ⭐⭐⭐⭐☆          | Medium         |
| Prewitt | 3×3        | ❌ No     | ⭐⭐☆☆☆          | Slightly thicker |
| Canny   | Adaptive   | 🤖 Auto   | ⭐⭐⭐⭐⭐          | Thin & precise |

## 🚨 Common Issues & Fixes

### ❌ Image Not Found Error
- Ensure `img.jpg` is in the same folder as your script 📁
- Use absolute path: `cv2.imread(r'C:\path\to\your\img.jpg')`

### 🖼️ Output Looks Too Dark/Light
- Add normalization:
```python
sobel_edges = cv2.normalize(sobel_edges, None, 0, 255, cv2.NORM_MINMAX)
```

### 🔍 Want Thicker/Thinner Edges?
- Increase kernel size for Sobel/Prewitt (max 7×7)
- Adjust Canny thresholds:
```python
cv2.Canny(gray, 50, 150)  # Thinner edges
cv2.Canny(gray, 150, 250)  # Thicker edges
```
