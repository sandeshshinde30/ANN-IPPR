# Image Processing with Spatial and Frequency Domain Filters 📈🔍

## Objective 🎯
Learn to apply different image processing filters for:
- Noise reduction (De-noising) 🎧
- Image smoothing 🖌️
- Image sharpening 🔪
Using both spatial and frequency domain approaches.

## Key Concepts 📚

### 1. Spatial Domain Processing 🌌
Direct manipulation of pixel values in the image plane.

#### 🌀 Gaussian Blur
- **What**: Smoothing filter that reduces high-frequency components
- **How**: Uses Gaussian function to weight neighboring pixels
- **Effect**: Reduces noise and details

#### 🛡️ Median Blur
- **What**: Non-linear filter for noise reduction
- **How**: Replaces pixel value with median of neighborhood
- **Best For**: Salt-and-pepper noise

#### 🔪 Sharpening
- **What**: Enhances edges and details
- **How**: Uses convolution kernel to emphasize intensity differences
- **Kernel Magic**: [[-1,-1,-1], [-1,9,-1], [-1,-1,-1]]

### 2. Frequency Domain Processing 📡
Processing image in Fourier transform space.

#### 🌀 Low-pass Filter
- **What**: Allows low frequencies to pass
- **Effect**: Smoothing/blurring
- **Implementation**: Mask central frequencies in Fourier domain

#### 🏹 High-pass Filter
- **What**: Allows high frequencies to pass
- **Effect**: Edge enhancement/sharpening
- **Implementation**: Block central frequencies in Fourier domain

## Code Explanation 💻

### Dependencies 📦
- `OpenCV`: Image I/O and spatial operations
- `NumPy`: Numerical operations and FFT
- `Matplotlib`: Visualization

### Spatial Processing Steps 🖼️
1. **Gaussian Blur**: `cv2.GaussianBlur()`
   - Kernel size (5,5), Sigma=0 (auto-calculate)
2. **Median Blur**: `cv2.medianBlur()`
   - Kernel size 5 (must be odd)
3. **Sharpening**: `cv2.filter2D()` with custom kernel

### Frequency Processing Steps 📊
1. **Fourier Transform**: `np.fft.fft2()`
2. **Shift Zero Frequency**: `np.fft.fftshift()`
3. **Create Masks**:
   - Low-pass: White circle in center
   - High-pass: Black circle in center
4. **Apply Mask & Inverse FFT**: `np.fft.ifft2()`

## Results Interpretation 🔍
- **Gaussian vs Median**: Compare noise reduction effectiveness
- **Sharpened Image**: Look for enhanced edges
- **Low-pass**: Should look blurred
- **High-pass**: Should show edges only

## Pro Tips 💡
- Adjust kernel sizes (must be odd numbers) for different effects
- Modify mask sizes in frequency domain (30 in code) to control cutoff frequency
- For color images, process each channel separately
- Normalize images before display (0-255 range)
