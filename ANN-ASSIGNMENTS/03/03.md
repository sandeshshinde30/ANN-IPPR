# 🔁 Delta Learning Rule Implementation  
## 🧠 Training a Network with 3 Inputs  

### 🔍 Objective  
Implement the **Delta Learning Rule** to train a single neuron network with 3 input features.  
- **Learning rate (c)**: 0.1  
- **Activation scaling (λ)**: 1  
- **Linear activation function**: $ a = \lambda \cdot \text{net input} $

---

## 🧮 Mathematical Foundation  

### Delta Rule Formula  
$$
\Delta w_i = c \cdot \lambda \cdot (t - a) \cdot x_i
$$  
Where:  
- $ \Delta w_i $: Change in weight for input $ i $  
- $ c $: Learning rate (0.1)  
- $ \lambda $: Activation scaling (1)  
- $ t $: Target output  
- $ a $: Actual output ($ a = \lambda \cdot \sum w_i x_i $)  
- $ x_i $: Input value  

---

## 📥 Input Data  

### Training Examples  
| Input Pattern | Feature 1 | Feature 2 | Feature 3 | Target |
|---------------|-----------|-----------|-----------|--------|
| X₁            | 1         | 0         | 1         | 1      |
| X₂            | 0         | 1         | 0         | 0      |
| X₃            | 1         | 1         | 0         | 1      |

### Variables in Code  
```python
X = np.array([[1, 0, 1], [0, 1, 0], [1, 1, 0]])  # Input patterns
y = np.array([1, 0, 1])                          # Target outputs
weights = np.zeros(3)                            # Initial weights
```

---

## 🧠 Training Process  

### Step-by-Step Logic  

1. **Forward Pass**  
   Compute net input:  
   $$
   \text{net} = w_1x_1 + w_2x_2 + w_3x_3
   $$  
   Apply activation:  
   $$
   a = \lambda \cdot \text{net}
   $$

2. **Error Calculation**  
   $$
   \text{error} = t - a
   $$

3. **Weight Update (Delta Rule)**  
   $$
   w_i = w_i + c \cdot \lambda \cdot \text{error} \cdot x_i
   $$

4. **Iterate Over Epochs**  
   Repeat for multiple epochs to refine weights.

---

## 🧪 Python Implementation  

```python
import numpy as np

# Parameters
c = 0.1        # Learning rate
lambda_ = 1    # Activation scaling factor

# Training data
X = np.array([[1, 0, 1], [0, 1, 0], [1, 1, 0]])  # Input patterns
y = np.array([1, 0, 1])                          # Target outputs

# Initialize weights
weights = np.zeros(3)

# Training loop
epochs = 10
for epoch in range(epochs):
    for i in range(len(X)):
        # Forward pass
        net_input = np.dot(weights, X[i])
        prediction = lambda_ * net_input
        
        # Error calculation
        error = y[i] - prediction
        
        # Weight update
        weights += c * lambda_ * error * X[i]
    
    print(f"Epoch {epoch+1} weights: {weights}")
```

## 🧠 Key Concepts  

### Why This Works  
- **Linear separability**: The dataset is linearly separable, so the Delta Rule converges.  
- **Role of λ**: Scales the gradient; set to 1 for linear activation.  
- **Bias Term**: Not included here for simplicity, but often added in practice.

### Limitations  
- Fails for non-linearly separable data (needs backpropagation instead).  
- Requires labeled data for supervised learning.
