# Hebbian Learning Explained 🧠✨

## 🎯 Objective
Implement a simple neural network using Hebbian learning rule to demonstrate:
- Weight updates based on input patterns
- Unsupervised learning mechanism
- Pattern association learning

## 📚 Core Concept: Hebb's Rule
**Donald Hebb's Postulate (1949):**
> "When an axon of cell A is near enough to excite cell B and repeatedly or persistently takes part in firing it, some growth process or metabolic change takes place in one or both cells such that A's efficiency, as one of the cells firing B, is increased."

**Mathematical Formulation:**
Δw_ij = η * x_i * y_j

Where:
- Δw_ij: Weight change between neuron i and j
- η: Learning rate (0 < η ≤ 1)
- x_i: Input from pre-synaptic neuron
- y_j: Output of post-synaptic neuron

## 🧩 Code Breakdown

### 1. Input Patterns
```python
inputs = np.array([
    [1, 0, 1],  # Binary patterns
    [0, 1, 1],   # representing different
    [1, 1, 0]    # input combinations
])
Three distinct 3-feature patterns

Binary values (0/1) for simplicity

2. Weight Initialization
python
weights = np.random.uniform(-0.2, 0.2, size=(3,))
Small random weights (-0.2 to 0.2)

Avoids initial symmetry issues

Matches input dimension (3 weights)

3. Learning Process
python
for epoch in range(epochs):
    for x in inputs:
        y = np.dot(x, weights)        # Forward pass
        delta = learning_rate * x * y # Hebbian update
        weights += delta              # Apply changes
Epochs: Complete passes through all patterns

Pattern Presentation: Sequential processing

Weight Update: Strengthens active connections

🧮 Mathematical Example
Let's walk through first pattern update:

Initial Weights: [0.173, -0.043, 0.099]
Input Pattern 1: [1, 0, 1]

Compute Output:
y = (1×0.173) + (0×-0.043) + (1×0.099) = 0.272

Calculate Weight Changes:
Δw = 0.1 × [1, 0, 1] × 0.272 = [0.0272, 0, 0.0272]

Update Weights:
New Weights = [0.2002, -0.043, 0.1262]

💡 Key Characteristics
Unsupervised Learning: No target outputs needed

Local Learning Rule: Uses only pre/post synaptic activity

Correlation-Based: Strengthens co-active connections

Weight Growth: Needs normalization for practical use

⚠️ Limitations & Solutions
Limitation	Solution
Unlimited weight growth	Weight normalization
No error correction	Oja's Rule (Δw = η(yx - y²w))
Linear separability	Non-linear activation functions
