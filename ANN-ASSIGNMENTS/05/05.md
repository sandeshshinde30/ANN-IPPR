# Handwritten Digit Classification Guide 🔢✨

## 🎯 Objective
Build a neural network to recognize handwritten digits (0-9) using:
- TensorFlow/Keras framework
- MNIST dataset
- Multi-layer perceptron (MLP) architecture

## 📚 Key Concepts

### 1. MNIST Dataset
- 60,000 training + 10,000 test images
- 28x28 grayscale images of handwritten digits
- Each pixel value: 0-255 (black to white)

### 2. Data Preprocessing
- **Normalization**: Scale pixel values to [0,1] range (`/255`)
- **Reshaping**: Flatten 28x28 images → 784-dim vectors
- **One-Hot Encoding**: Convert labels to categorical format

### 3. Neural Network Architecture
```python
Sequential(
    Dense(128, relu) → Dense(64, relu) → Dense(10, softmax)
)
```
- **Input Layer**: 784 neurons (1 per pixel)
- **Hidden Layers**: 128 → 64 neurons with ReLU activation
- **Output Layer**: 10 neurons (1 per digit) with Softmax

### 4. Training Configuration
- **Optimizer**: Adam (adaptive learning rate)
- **Loss Function**: Categorical Crossentropy
- **Metrics**: Accuracy
- **Batch Size**: 128 samples per update
- **Epochs**: 10 full dataset passes

## 🧠 How Neural Networks Learn
1. **Forward Propagation**:
   - Input → Hidden Layers → Output
   - Calculate predictions using current weights

2. **Loss Calculation**:
   - Compare predictions with true labels
   - Compute cross-entropy loss

3. **Backpropagation**:
   - Calculate gradients using chain rule
   - Update weights to minimize loss

4. **Weight Update**:
   - Adam optimizer adjusts learning rates automatically
   - ReLU activation helps prevent vanishing gradients

## 📊 Interpreting Results
### Accuracy Curves
- **Training Accuracy**: Model performance on training data
- **Validation Accuracy**: Performance on held-out validation set
- **Good Fit**: Both curves increase and stabilize
- **Overfitting**: Large gap between train/val accuracy
