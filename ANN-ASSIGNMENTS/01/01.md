
# Perceptron Learning Rule Implementation

This implementation trains a perceptron with three input features using the Perceptron learning rule.

## Key Components

1. **Perceptron Class**
   - `__init__`: Initializes weights, learning rate, and training epochs
   - `fit`: Implements the training loop with weight updates
   - `predict`: Makes predictions for new inputs

2. **Algorithm Details**
   - Inputs are augmented with a bias term (1) during training and prediction
   - Weight update rule: 
     ```
     weights += learning_rate * (target - prediction) * augmented_input
     ```
   - Uses sign activation function for binary classification (-1 or 1)

3. **Example Usage**
   - **Training Data**: Four samples with three features each
   - **Initial Weights**: [0, 0, 0, 0] (including bias term)
   - **Learning Rate**: 0.1
   - **Epochs**: 100

4. **Test Results**
   - After training, the model should:
     - Learn weights that separate the classes
     - Predict correctly on linearly separable test data

## Running the Code

1. Save the code as `perceptron.py`
2. Run with: `python perceptron.py`
3. Expected output:
   ```
   Learned weights: [ 0.2  0.2  0.2  0.2]
   Predictions for test samples: [ 1. -1.]
   ```

## Key Notes
- The implementation assumes binary classification (-1/1)
- Data must be linearly separable for guaranteed convergence
- Learning rate and epochs can be adjusted for different datasets
